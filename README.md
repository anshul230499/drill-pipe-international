# Drill Pipe International — GitHub / Vercel website

**Repository and Vercel project:** `drill-pipe-international`

This is a static site. Upload `index.html`, `assets/dpi-logo.jpg`, `vercel.json`, and the optional documentation files directly into the root of the GitHub repository. Vercel framework preset: **Other**. No install/build command or environment variables required.

The website positions DPI as a wholly owned subsidiary of Jindal SAW USA, LLC and explains that the full drill pipe production chain is performed in-house within the Jindal group, distributed across facilities (not all in Baytown).

**Imagery:** External Pexels/Unsplash images are stock/representative photographs only, *not Jindal or DPI facility photographs*. The included logo is sourced from the DPI quotation document. Replace stock photography with approved in-house production assets when available. See `RESEARCH_NOTES.md`.

**Important contact form behavior:** The enquiry form prepares a `mailto:` email addressed to `info@drillpipeinternational.com`. It does **not** send an email by itself; the visitor must send it in their email application. For reliable browser form submissions, connect a real form backend, e.g. Formspree or a Vercel serverless route with an email provider.

After pushing to GitHub, connect the repository under the project's Vercel **Settings → Git**, then redeploy.
